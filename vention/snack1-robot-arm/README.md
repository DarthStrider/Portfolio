# Robot Arm in the Browser

**Stack:** Three.js, TypeScript, glTF  
**Effort:** ~1.5 days  
**Status:** Not started

A jointed robot arm rendered in the browser with live forward kinematics.

## Features

- [ ] 3- or 4-joint arm built as an `Object3D` hierarchy; each joint rotates on its own axis
- [ ] Forward kinematics: show the end-effector's world position live
- [ ] Load one part as glTF (reusing Hoppin World experience)
- [ ] Orbit camera, grid floor, simple lighting

## Talking point

"Same transform hierarchy as Unity; here's what's different in Three.js."
