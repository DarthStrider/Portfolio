# React Control Panel

**Stack:** React, TypeScript, react-three-fiber or Three.js  
**Effort:** ~1 day  
**Status:** Not started

A React UI driving the robot arm from Snack 1.

## Features

- [ ] Sidebar with a slider per joint, plus Play/Pause for a scripted motion sequence (pick → move → place)
- [ ] State lives in React; the 3D scene reads it (react-three-fiber, or a plain Three.js scene with a ref)
- [ ] UI state connected to the simulation without re-rendering the whole scene each frame

## Talking point

Echoes MachineLogic, which simulates robot sequences before purchase.
